# 安全报告 / Security reporting

[中文](#中文) · [English](#english)

<a id="中文"></a>

## 中文

如果你发现可能影响 XuanPian 用户的安全问题，请通过 GitHub 的[私密漏洞报告](https://github.com/zhouz1995-svg/xuanpian/security/advisories/new)提交。请勿为未公开漏洞创建公开 Issue，也不要上传私人照片、完整 EXIF、项目数据库、真实路径、凭据、签名身份或包含私人数据的利用样例。

报告应包含受影响版本、影响、最小复现步骤和已经完成的检查。请使用合成或明确可共享的素材，并对路径和元数据脱敏。如果私密报告入口暂时不可用，可以创建不含敏感细节的[普通 Issue](https://github.com/zhouz1995-svg/xuanpian/issues)，仅请求维护者建立私密联系渠道。

当前 0.1.0 测试版使用本地临时签名，尚未经过 Apple 公证。请勿为了运行应用而关闭 macOS 安全保护。供应链报告请注明准确的组件、版本和证据来源；锁文件中出现某个依赖并不自动证明它安全或适合再分发。

<a id="english"></a>

## English

Report potential vulnerabilities that affect XuanPian users through GitHub's [private vulnerability reporting](https://github.com/zhouz1995-svg/xuanpian/security/advisories/new). Do not open a public issue for an undisclosed vulnerability, and do not upload private photos, full EXIF, project databases, real paths, credentials, signing identities, or exploit material containing private data.

Include the affected version, impact, minimal reproduction, and checks already performed. Use synthetic or explicitly shareable material and redact paths and metadata. If private reporting is temporarily unavailable, open a [sanitized issue](https://github.com/zhouz1995-svg/xuanpian/issues) containing no sensitive details and ask the maintainer to establish a private channel.

The current 0.1.0 beta is locally ad-hoc signed and is not Apple-notarized. Do not disable macOS security protections to run it. Supply-chain reports should identify the exact component, version, and evidence source; presence in a lockfile is not proof that a dependency is safe or redistributable.
