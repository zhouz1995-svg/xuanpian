# Security reporting

This source candidate has no confirmed private vulnerability-report channel yet. Do not post a live credential, signing identity, exploit payload containing private data, private photo, EXIF, project database, or unredacted path in a public issue. Keep sensitive evidence local until maintainers provide a verified private channel. A sanitized issue can describe the affected version, impact, and reproduction conditions without secret values.

Do not disable macOS security protections to run an unsigned or ad-hoc-signed development build. The local candidate is not notarized or approved for public distribution. Security and supply-chain findings should identify the exact component/version and source of evidence without presuming a dependency is safe merely because it appears in a lockfile.
