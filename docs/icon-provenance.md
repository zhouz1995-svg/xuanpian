# Application icon provenance

On 2026-10-12, the project owner confirmed that the application icon was
created specifically for this project by the coding assistant during the
project design conversation. The owner confirmed that no third-party artwork
or stock asset was supplied or incorporated.

The design record at
`docs/superpowers/specs/2026-08-01-interface-and-app-icon-design.md` describes
the project-specific “stacked photos + check mark” concept. Git history records
the introduction and later loading/rebuilding of the assets in commits
`3270546`, `fb53ac9`, and `d29f338`. `assets/icons/app-icon-1024.png` is the
shared master; the PNG sizes, macOS iconset/ICNS, Windows ICO, and runtime PNG
are derived variants. `scripts/rebuild_icons_alpha.py` documents later
deterministic variant processing.

To the extent copyright subsists in this AI-assisted project asset, it is made
available with the project under GPL-3.0-only. This provenance statement does
not assert trademark registration, exclusive rights in common photographic or
check-mark motifs, or a guarantee that no independently created mark is
similar. A separate name/logo trademark search remains appropriate before a
commercial launch.
